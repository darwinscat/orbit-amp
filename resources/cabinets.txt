# THE CABINET CATALOG: every cabinet IR a Darwin's Cat amp carries, each said ONCE, here. CMake reads it
# (cmake/CabinetCatalog.cmake) to put the files into the binaries — Darwin's Cat's own into the data every
# product links, the rest into the data OrbitAmp alone links — and to write the table the code plays them
# by (<build>/generated/CabinetCatalog.h): the names and the default of the `cab_ir` parameter, the
# shelf's folders the products lay them out in (src/device/FactoryShelf.h), and the cabinets the IR menu
# shows them by (src/Parameters.h, cabShelves).
#
# ADDING A CABINET IR IS ONE LINE: an `ir` line under its cabinet, with the next number nobody has had,
# and its file in the tree. A new cabinet is a `cabinet` line with its IRs under it; a new maker's, a
# `folder` line as well. The menu shows a cabinet as one run of numbers, so a new IR goes under the
# cabinet that holds the last number, or under a cabinet of its own — CMake says so when it does not.
#
# Four kinds of line, their fields parted by `|` (the spaces around a field are not part of it):
#
#   folder  | <name> | <who carries it>
#       A folder of the shelf, under Factory/IRs. `every product` is the folder the faces lay out and
#       list too — one folder is — and `OrbitAmp` is one that OrbitAmp alone carries: in a face its
#       places are held with nothing in them.
#
#   cabinet | <folder> | <about>
#       A cabinet, in the order the IR menu shows them: the folder its IRs lie in, and the line that
#       heads them in that folder's submenu — the cabinet, its speakers, where they come from.
#
#   ir      | <number> | <name> | <file>
#       An IR of the cabinet above it. THE NUMBER IS FOR GOOD: what a session or a preset keeps of its
#       cabinet is this number, so it never moves and is never given to another IR — a session saved on
#       WUMBO opens on WUMBO. The numbers run from 0 with none left out, and a cabinet's IRs stand in
#       one run of them, in the order the menu shows them. The name is the one the player reads; the
#       file is under resources/, and its name is the one it is laid out under, so no two may share one.
#
#   default | <name>
#       The cabinet a fresh instance opens on, and every face's channels too.
